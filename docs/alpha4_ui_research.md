# Alpha 4 — Дослідження UI та шрифтів (зведення)

Цей документ зібрано на основі паралельного дослідження (агенти 1–3) та аналізу поточної реалізації ATOF (`engine.py`: HUD/радар, `WeaponWheel`, підказки взаємодії, меню).

## 1. UI у стилі GTA 5 / GTA 6 (практичні висновки)

### Принципи
- **Контекстний HUD:** показувати елементи лише коли вони потрібні (патрони/стан — ситуативно), мінімум шуму під час руху/бою.
- **Ієрархія:** критичне (здоров’я, загроза, напрямок) читається миттєво; другорядне — в меню/оверлеях.
- **Єдина візуальна мова:** спільні токени (кольори, радіуси, відступи, альфа, типографіка).
- **Recognition over recall:** швидкий вибір (колесо) показує варіанти візуально.

### Патерни для ATOF (2D, Pygame)
- **Радар/мінімапа:** заокруглена/кругла форма, напівпрозора підкладка, чіткі маркери (гравець, ціль, POI), мінімум зайвих іконок, контрастна рамка/скло.
- **Статус-бари:** фон+заповнення+обводка/блік, плавна інтерполяція/«шлейф» при зміні, стани low (пульс/колір) без надмірного мерехтіння.
- **Колесо швидкого вибору:** радіальні сектори, вибір через `atan2`, затемнення світу, активний сектор яскраво підсвічений, у центрі — поточний вибір (іконка/назва/характеристика), плавне відкриття (150–250 мс), підтримка миші.
- **Меню/панелі:** темні напівпрозорі панелі (скло/мат), акцентний фокус-пункт, чітка навігація, великі відступи.
- **Підказки/нотифікації:** `[KEY] Дія` у бейджі, стек/пріоритет, короткі slide+fade анімації.

### Візуальна мова
- **Кольори:** темна база панелей, 1–2 акценти бренду + семантичні (здоров’я/небезпека/ресурс/гроші), стан не лише кольором.
- **Скло:** `SRCALPHA`-панелі, напівпрозорий фон + тонка світла обводка/блік; blur-ефект — обережно/кешовано.
- **Анімації:** 120–300 мс з easing, фідбек на дію гравця, інтерполяція значень барів.
- **Іконографія:** прості силуети, єдина сітка/вага, стани normal/selected/disabled.

## 2. UI у стилі інших популярних ігор (узагальнені практики)

### Референси та що брати
- **Cyberpunk 2077:** неон/техно, скошені кути, тонкі рамки, акцентні кольори, глітч лише як короткий фідбек.
- **Forza Horizon:** мінімалізм, жирна типографіка, повітря, плавні переходи, картки/плитки, швидка навігація.
- **Watch Dogs:** контурна/лінійна геометрія, монохром+акцент, spatial-підказки.
- **Destiny:** sci-fi елегантність, дуги/кільця, м’яке світіння, вивірена типографіка, акуратні радіальні/меню елементи.
- **Сучасні інді/AAA (Hades, Dead Cells тощо):** мінімальний HUD, сильний силует/фідбек, великі зрозумілі іконки та стани.

### Спільні кращі практики
- Читабельність і контраст на будь-якому фоні (backplate, обводка/тінь), критичне ближче до зони уваги.
- Progressive disclosure / динамічний HUD (ховати зайве поза контекстом).
- Миттєвий фідбек (~<100 мс) + змістовні короткі анімації (150–300 мс, easing).
- Консистентність станів/кольорів/іконок; доступність (не лише колір, масштаб, зменшення руху).

### Ідеї для Pygame 2D
- Backplate/напівпрозорі панелі `SRCALPHA`, кешування статичних поверхонь, рендер шрифтів/ефектів не щокадру без потреби.
- Дешеве «скло»: напівпрозорий прямокутник + світла рамка; glow — кілька шарів/альфа.
- Рух/анімації через `dt` + easing/tween; інтерполяція відображуваних значень (HP/бари).
- Радар на окремій поверхні з маскою; колесо — секторна геометрія + `atan2`.

## 3. Шрифт (кросплатформно, CC0/CC-BY сумісний)

### Рекомендація
- **Основний:** **Inter** (SIL Open Font License 1.1 — вільна, комерційне використання/вбудовування дозволено; додати `OFL.txt`).
- **Чому:** UI-орієнтований (читабельність на малих розмірах), покриття Latin+Cyrillic+Greek (UA/RU/EN/ES/DE/FR), статичні hinted TTF для стабільного рендерингу (зокрема Windows), багато накреслень.
- **Альтернатива:** Noto Sans (OFL 1.1) — максимально універсальний/нейтральний.

### Джерела
- Inter: https://rsms.me/inter/ , релізи https://github.com/rsms/inter/releases (пакет з TTF/OTF, напр. `extras/ttf` hinted), Google Fonts https://fonts.google.com/specimen/Inter
- Noto Sans: https://fonts.google.com/noto/specimen/Noto+Sans

### Інтеграція в Pygame (однаковий вигляд на ОС)
- Бандлити шрифт у проєкті (наприклад `assets/fonts/Inter/*.ttf`) і завантажувати **лише** через `pygame.font.Font(path, size)` (не `SysFont`).
- Будувати шлях відносно файлу/кореня ресурсів, створювати `Font` один раз і кешувати, `antialias=True`, кешувати відрендерені статичні рядки, не масштабувати текстові `Surface` довільно.
- Для HUD/меню: Regular/Medium/SemiBold/Bold за ієрархією.

## 4. План впровадження в Alpha 4 (узгоджено з поточною архітектурою)
- **Шрифт:** додати бандлений OFL-шрифт (Inter) у ресурси, перемкнути `_FONT_PATH`/`load_game_fonts`/кеш на нього з fallback, зберегти консистентність на Win/macOS/Linux.
- **Колесо швидкого вибору (`WeaponWheel`):** зберегти поточний алгоритм/організацію (стан `wheel_open`, вибір сектором через `atan2` від центру, слоти `wheel_slots`, відкриття/закриття на MMB) і покращити візуал у стилі GTA/сучасних ігор (скляне кільце, чіткі сектори, підсвітка активного, центр із поточним вибором, читабельні підписи/іконки, плавніший фідбек).
- **HUD/панелі/меню:** уніфікувати скляні напівпрозорі панелі, контраст, акценти й типографічну ієрархію (радар уже оновлено — узгодити решту елементів: підказки, меню збереження/налаштувань, оверлеї) без перевантаження.
- **Документація/реліз:** зафіксувати зміни в README, оновити версію до 0.9.0-alpha.4, коміт і пре-реліз.

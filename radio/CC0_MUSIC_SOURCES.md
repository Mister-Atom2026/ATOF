# Radio music sources

The bundled station tracks below are marked CC0 1.0 on their linked source
pages. CC0 allows copying, modification, redistribution, and commercial use
without requesting permission; attribution is optional. ATOF keeps artist and
source credits here as a courtesy. Please retain this file when distributing
the bundled recordings.
